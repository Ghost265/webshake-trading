# Sicherheitsregeln Webshake Trading

- Start immer im Paper-Trading.
- Echtes Trading erst nach stabilen Tests.
- Not-Aus muss jederzeit erreichbar sein.
- Tagesverlustlimit ist Pflicht.
- Strategieänderungen werden erst simuliert und erklärt.
- Der Nutzer muss neue Strategien bestätigen, außer die Einstellung erlaubt automatische Optimierung.
- Futures bleiben deaktiviert.
